Code signing certificate of the downloadable MediaTidy.app (self-signed, not from Apple).
It keeps the app's identity stable, so macOS keeps Full Disk Access across updates.
The private key is only stored as the GitHub secret MEDIATIDY_SIGN_P12 (+ MEDIATIDY_SIGN_PASSWORD).
Check a downloaded app:  codesign -d -r- /Applications/MediaTidy.app
